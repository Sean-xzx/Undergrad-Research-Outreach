# Design and architecture / 设计与架构

The project turns an undergraduate's current obstacle into a next action toward a real research opportunity. It is an author-led, AI-assisted instruction design, not a trained model or a standalone application. The contribution is the workflow organization and its evidence constraints; algorithmic novelty and improved acceptance rates have not been established.

本项目以本科生的当前困境为入口，推进真实科研机会。贡献在于流程组织、证据约束与低负担交互，不声称已验证算法创新或接收率提升。

| Module | Responsibility / 职责 |
| --- | --- |
| [SKILL.md](../undergrad-research-outreach/SKILL.md) | Stage routing, shared factual boundaries and one next step / 阶段选择、事实边界及下一步 |
| [opportunities.md](../undergrad-research-outreach/references/opportunities.md) | Eligibility, professor identity, task fit and realistic time/location / 条件、身份、任务与时间地点匹配 |
| [writing.md](../undergrad-research-outreach/references/writing.md) | Paper entry, personal contribution, CV, main email and pre-send review / 论文入门、个人贡献、材料与邮件 |
| [follow-through.md](../undergrad-research-outreach/references/follow-through.md) | Contact state, replies, follow-up, interviews, trial tasks and confirmation / 跟进、回复、面谈、试做与确认 |
| [records.md](../undergrad-research-outreach/references/records.md) | Minimal reusable profile, sources and contact events / 最小背景、来源与真实联系记录 |
| [learning.md](../undergrad-research-outreach/references/learning.md) | Source reading, contextual adoption and revision / 来源阅读、按情境采纳与修订 |

**Flow / 信息流：**student material + official professor/paper sources → grounded fit and unknowns → one draft or action → actual contact event → reply/next step → confirmed arrangements or closure.

Personal facts, professor facts, assistant inference and the student's own reading are kept distinct. A model's explanation is not evidence that the student read a paper. No reply is an unresolved contact state; an interview or trial invitation is not confirmed entry. A weak match can become a smaller request or a different target.

学生事实、教授事实、助手推断及学生实际阅读范围分别记录。解释论文不等于学生已读；未回复不能推断拒绝；面谈或试做邀请不等于接收。弱匹配可缩小请求或调整目标。

The seven v1.0 source files are preserved byte for byte. Repository tooling is separate: validation checks fingerprints and links; packaging selects only those seven files. Private records belong in the user's working project and are never part of the public package.

7 个原始文件逐字节保留；仓库验证和打包工具独立，私人记录留在用户工作项目，不进入公开包。Sources and adoption limits: [source index](sources.md). Verification boundaries: [validation](validation.md).
