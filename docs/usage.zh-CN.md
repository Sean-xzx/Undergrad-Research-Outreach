# 操作指南

按 README 安装 skill 后，在支持该技能的 Codex 聊天中明确写出：

> 用 $undergrad-research-outreach 帮我推进本科生科研套磁。我是某专业某年级，想获得暑期科研或进组机会，目前卡在不知道找谁。请从这一步开始，每轮给一份主要成果和一个具体下一步。

背景不齐时直接说明已知情况。可以附简历或提供本机完整路径；已有目标时给官方主页；已有草稿或教授回复时贴原文。助手整理已有材料，再只补问当前决策需要的缺项。

| 进度 | 直接提出的任务 |
| --- | --- |
| 找导师 | 根据专业、兴趣、实际时间与地点找少量候选，附官方来源和理由 |
| 已有导师 | 判断匹配，选择一项可理解的研究工作 |
| 不懂论文 | 解释当前不懂的部分，给一个最小阅读任务 |
| 准备发信 | 用确认的事实生成一份主稿，标明必要待补项 |
| 已有邮件 | 保留真实表达，核实事实与请求后修改 |
| 已发送 | 提供发送日期和原邮件，判断下一步是否适合跟进 |
| 收到回复 | 贴回复原文，准备材料、回应、面谈或试做 |
| 得到机会 | 确认实际指导、工作、开始时间、投入与手续 |

发送前核对身份、经历、论文表述、承诺和附件。“待补稿”需先补必要事实；“可发送”不代表已经发出。可以自行发送并告知实际日期；要求代发时须明确正文、目标和附件，并具备相应工具。

多轮使用时可要求：“把确认的个人情况和联系进度保存在当前项目；下次先读记录再继续。”记录由助手维护，不进入公开 skill 包。新情况或时间改变时直接更新。

未自动发现 skill 时，要求宿主读取本仓库的 `undergrad-research-outreach/SKILL.md` 和当前阶段需要的参考文件。无需将所有指导逐次粘贴到聊天。

这是使用说明；宿主工具能力、联网来源和实际科研接收条件仍须在使用时核实。详见[验证范围](validation.md)。
